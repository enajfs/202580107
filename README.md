## How It Works
1. Create an account by accessing the registration form.
2. Log in to your account.
3. Browse into the shop page to find the order you want to place.
4. Add to cart the item you like and input the variants you like.
5. Input the needed information being asked.
6. Click place order.

## Getting Started

### Prerequisites

- Node.js 20+
- npm 10+

### Installation

```bash
git clone https://github.com/enajfs/202580107.git
cd 202580107
npm install
```

### Running Locally

```bash
npm run dev
```

Open http://localhost:3000 to view the app.
